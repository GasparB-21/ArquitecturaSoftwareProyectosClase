# ArquitecturaSoftwareProyectosClase

Repositorio con los distintos proyectos realizados en las clases de la asignatura: Arquitectura del Software.

## Contenido

- `Clase_02-05-26/`: proyecto de ejemplo con una aplicación TODO en Python.
- `Clase_02-12-26/`: primer proyecto Django con un `manage.py` y una aplicación básica.

## Cómo ejecutar cada proyecto

1. Ejecutar TODO APP:
   - Ir a la carpeta `Clase_02-05-26/`.
   - Ejecutar `python todo-app.py`.
   - Nota: hay que ejecutar `todo-app.py` desde la carpeta que lo contiene.

2. Ejecutar el primer proyecto Django:
   - Ir a la carpeta `Clase_02-12-26/`.
   - Ejecutar `python manage.py runserver`.
   - Es necesario tener instalado Django.
